# Snake Game

一個使用 React、TypeScript 與 Canvas 製作的經典貪食蛇遊戲。

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

`npm run build`
